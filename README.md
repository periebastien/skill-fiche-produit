# Skill « fiche-produit » (boutique Plaine Altitude)

Skill Claude Code qui crée une fiche produit en brouillon sur la boutique Plaine Altitude à partir de la page ou du PDF d'un
fabricant, en posant les questions de vente avant l'envoi. Installation et mise à jour : `INSTALLATION.md`.

Ce dépôt est une copie publiée : la source est dans le dépôt de la boutique (`outils/fiches-assistees/skill/fiche-produit/`),
envoyée ici par `outils/fiches-assistees/publier-skill.sh`. Ne pas modifier les fichiers directement ici.
